## ✨ What is Learnova AI?

**Learnova AI** is an AI-powered learning platform that helps students transform their syllabus into a structured and personalized learning experience.

Instead of asking:

> **"What should I study?"**

Learnova AI helps answer:

> **"What should I study, how should I study it, and how can I practice it?"**

---

## 🌟 Features

| Feature | Description |
|---|---|
| 📚 **AI Syllabus Analysis** | Upload your syllabus and extract units, topics and important concepts |
| 🧠 **AI Lessons** | Generate clear, beginner-friendly lessons for topics |
| 📅 **Study Planner** | Create personalized day-by-day study plans |
| 📝 **AI Quizzes** | Generate topic-based multiple-choice quizzes |
| 🔐 **Authentication** | Secure signup, login and protected APIs |
| 📊 **Progress Tracking** | Track learning activity and progress |
| 🌙 **Modern Dashboard** | Clean and modern AI-focused learning interface |
